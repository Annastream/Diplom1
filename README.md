## Структура проекта
### Основные директории и файлы
**Корневая директория проекта содержит:**
- `.venv/` - виртуальное окружение Python (в .gitignore)
- `allure-report/` - сгенерированные отчеты Allure (в .gitignore)
- `helpers/` - вспомогательные модули:
  - `api_requests.py` - клиент для работы с API
  - `user_helpers.py` - дополнительные функции для работы с пользователями
- `tests/` - тестовые сценарии:
  - `conftest.py` - фикстуры Pytest
  - `test_order_creation.py` - тесты создания заказов
  - `test_user_creation.py` - тесты регистрации пользователей
  - `test_user_login.py` - тесты авторизации
- `data.py` - тестовые данные и конфигурация
- `requirements.txt` - зависимости проекта
- `README.md` - документация проекта

### Вспомогательные файлы
- `.gitignore` - список исключений для Git
- `External Libraries` - ссылки на внешние библиотеки (автоматически генерируется IDE)
- `Scratches and Consoles` - временные файлы IDE (в .gitignore)

## Тестовые сценарии
#### Создание пользователя (`test_user_creation.py`)
- Создать уникального пользователя.
- Создать пользователя, который уже зарегистрирован.
- Создать пользователя без заполнения одного из обязательных полей.

#### Логин пользователя (`test_user_login.py`)
- Авторизация существующего пользователя.
- Попытка авторизации с неверным логином и паролем.

#### Создание заказа (`test_order_creation.py`)
- Создание заказа с авторизацией.
- Создание заказа без авторизации.
- Создание заказа с ингредиентами.
- Попытка создания заказа без ингредиентов.
- Попытка создания заказа с неверным хешем ингредиентов.

### Структура проекта

- `data/` - содержит данные для тестов.
